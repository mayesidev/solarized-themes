# T3 Code

Import [solarized.json](solarized.json) in **Settings → Appearance**. The native
T3 Code theme includes both light and dark modes under **Solarized**.

Tested with T3 Code desktop v0.1.2 on macOS.

Adapted from the Visual Studio Code Solarized themes:

- [Dark](https://github.com/microsoft/vscode/blob/b3ff02a27ab7884ad0556a8049f3f35758481b1d/extensions/theme-solarized-dark/themes/solarized-dark-color-theme.json)
- [Light](https://github.com/microsoft/vscode/blob/b3ff02a27ab7884ad0556a8049f3f35758481b1d/extensions/theme-solarized-light/themes/solarized-light-color-theme.json)
